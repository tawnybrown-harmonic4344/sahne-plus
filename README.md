## 🧪 Troubleshooting Common Issues

### ❌ Sahne+ won't start
- Make sure you're using Windows 10 or 11.
- Try right-clicking the file and selecting **"Run as administrator"**.
- Check if your antivirus is blocking it. If so, add an exception.

### ❌ Alerts don't appear during stream
- Ensure your Kick/KickBot connection is active (check the "Connected" status in the app).
- Test with the **"Test Alert"** button first.
- Make sure Sahne+ is running **before** you start your stream.

### ❌ Media looks stretched or blurry
- Use images/GIFs with a transparent background (PNG or GIF format).
- Recommended resolution: 1920x1080 or smaller for best performance.
- Avoid overly large files (keep under 10 MB for smooth performance).

### ❌ Sound doesn't play
- Check that your system volume isn't muted.
- Verify the audio file format is `.mp3` or `.wav`.
- Try a different audio file.
